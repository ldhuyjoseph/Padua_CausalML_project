Project Documentation

This document details the software architecture, helper functions, and machine learning pipelines used in the Believing and Sharing Information by Fake Sources project.

Environment Setup

The project utilizes the pacman package manager to ensure a reproducible computational environment.

pacman::p_load(tidyverse, DoubleML, mlr3, causalTree, hdm, glmnet, clubSandwich, stargazer)

Core Functions (Data Wrangling)

prep_data(df, outcome_var, covars)

Dynamically subsets the dataset for a specific modeling task, performing listwise deletion (NA omission) exclusively for the required variables to maximize retained sample size.

Arguments

ArgumentTypeDescription
dfdata.frameThe base dataset (e.g., datas_short).
outcome_varstringThe name of the dependent variable (e.g., "y_belief_report_num").
covarscharacter vectorThe vector of control variable names to be included in the model.

Returns

data.frame: A clean, NA-omitted subset ready for model fitting.

get_robust_se(model_obj)

Calculates heteroskedasticity-consistent standard errors (HC1) for a given linear model object.

Arguments

ArgumentTypeDescription
model_objlmA fitted linear model object.

Returns

numeric vector: A vector of robust standard errors for the model's coefficients.

Machine Learning Pipelines

run_post_lasso(y_var)

Executes a Post-LASSO methodology. It first fits a cross-validated LASSO model to select optimal features, then runs an OLS regression using only the non-zero selected variables.

Returns

lm object, or NULL if no variables were selected by the LASSO penalty.

run_double_ml(y_var)

Instantiates and fits an Interactive Regression Model (IRM) using the DoubleML package to estimate the Conditional Average Treatment Effect (CATE). It uses Gradient Boosting (gbm) for the nuisance functions (g and m).

Returns

DoubleMLIRM object containing the fitted causal model.
